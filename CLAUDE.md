# Kuko Visuals

Vanilla JS site built with Vite. Static, no framework.

## Structure

- `index.html` — home: title, paragraph, two link boxes
- `pages/study.html` — case studies page
- `src/main.js` — imports the stylesheet
- `src/style.css` — all styles

## Commands

- `npm install`
- `npm run dev`
- `npm run build`

## Rules

- Keep every line minimal.
- No colors, no extra design — rely on default CSS.
- Responsive with no media queries.
- Don't add anything not explicitly requested.
