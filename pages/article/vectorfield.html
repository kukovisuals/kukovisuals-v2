Reading a self Buffer

Playing with the buffers, since it's the most important thing in flow fields, we need to know how they work. Here is a simple setup to create a circle and read the same buffer, also called ping pong. What we're going to do is add some simple additive to the texture as vec2(1).

Then this is our Buffer A setup: a circle that simply moves with the texture so we can see how it works and how the circle leaves a trail as the texture moves.

Buffer A

void mainImage( out vec4 O, in vec2 I )
{
    vec2 R = iResolution.xy;
    vec2 mv = vec2(5);

    O = texelFetch(iChannel0, ivec2( (I - mv) -0.5) ,0) *.99;

    float d =length(( (I-R*0.5)) );
    O.xy += smoothstep(50.,0.,d);

    if(iFrame < 1) O = vec4(0);
}
